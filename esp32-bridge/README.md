# Lumina ESP32 Bridge firmware (1.2)

This folder holds the fielded bridge firmware, version 1.2 (`src/main.cpp`). What it does, how it is flashed at the bench, and the Firestore rules it depends on are in `docs/guides/internal/32-bridge-firmware.md`. Installer-facing setup is `docs/guides/installer/12-bridge-guide.md`.

There is no web page in this firmware and no other firmware tree. An earlier version of this file called this folder "legacy" and described a wizard and a dashboard that never existed.
