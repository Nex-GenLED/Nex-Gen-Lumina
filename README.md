# Nex-Gen Lumina

Nex-Gen Lumina is a Flutter mobile app for controlling permanent outdoor pixel-LED systems based on WLED. The app supports local Wi-Fi control and, with the dealer-installed Lumina Bridge (ESP32 + Firestore command relay), control from anywhere. It is provided to customers by installer invitation; it is not in the public app stores.
