# Nex-Gen Lumina

Nex-Gen Lumina is a Flutter mobile app for controlling permanent outdoor pixel-LED systems based on WLED. The app supports both local Wi-Fi control and remote control via the Lumina Bridge (ESP32 + Firestore command relay). For development, architecture, and operational details, see [CLAUDE.md](CLAUDE.md). User-facing documentation lives in [docs/](docs/).
